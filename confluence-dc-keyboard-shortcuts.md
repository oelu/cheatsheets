# Confluence Data Center: Keyboard Shortcuts Cheatsheet

> **Audience:** Confluence Data Center users who want to work faster with the keyboard.
> **Links verified:** 2026-10-24. Source: Atlassian, [Keyboard shortcuts (Confluence Data Center 11.0)](https://confluence.atlassian.com/doc/keyboard-shortcuts-139456.html).
> **Caveats:** Applies to Confluence **Data Center 11.0**; older versions and Confluence Cloud differ ([Cloud docs](https://support.atlassian.com/confluence-cloud/docs/keyboard-shortcuts-markdown-and-autocomplete)). The in-product dialog (`Shift + ?` while viewing a page, or the help icon → Keyboard Shortcuts) is authoritative and shows the keys for your OS and browser. The single-key "General" shortcuts can be switched off in the General tab of that dialog. Atlassian has announced the end of Data Center support for March 28, 2029.

## Global

Single keys, same on Windows and Mac. "then" means press one key after the other.

| Action | Key |
|---|---|
| Open shortcut help | `?` |
| Quick search | `G` then `G`, or `/` |
| Go to dashboard | `G` then `D` |
| Open notifications | `G` then `N` |
| Open recently viewed | `G` then `R` |
| Browse current space | `G` then `S` |
| Toggle space sidebar | `[` |
| Add page | `C` |
| Edit | `E` |
| Share | `S` |
| Show skip links | `U` then `8` |

## Autoformat (wiki markup)

Type in the editor; the formatting applies as you type. Same on Windows and Mac. Note that Data Center uses wiki markup, not Markdown: `*text*` is **bold**, not italic.

| Result | Type |
|---|---|
| Bold | `*text*` |
| Italic | `_text_` |
| Underline | `+text+` |
| Monospace | `{{text}}` |
| Heading 1 | `h1.` + Space, or `#` + Space |
| Heading 3 | `h3.` + Space, or `###` + Space |
| Quote | `bq.` + Space, or `>` + Space |
| Bullet list | `*` + Space, or `-` + Space |
| Numbered list | `1.` + Space |
| Task | `[]` |
| Horizontal rule | `---` |
| Table with n columns | `\|\|\|\|\|` + Enter (bar count sets column count) |
| Table with headings | `\|\|heading\|\|heading\|\|` + Enter |

Neither table pattern works inside an existing table.

## Panels (info, tip, note, warning)

There is no dedicated key combo. Type `{` or `/` plus the start of the macro name, then pick it from the list ([Info, Tip, Note, and Warning Macros](https://confluence.atlassian.com/doc/info-tip-note-and-warning-macros-51872369.html)).

| Type | Inserts |
|---|---|
| `{info` or `/info` | Info macro |
| `{tip` or `/tip` | Tip macro |
| `{note` or `/note` | Note macro |
| `{warning` or `/warning` | Warning macro |

Wiki markup (via `Ctrl/Cmd + Shift + D`), with optional `title` and `icon` parameters:

```
{info:title=This is my title|icon=false}
This is _important_ information.
{info}
```

|---|---|---|
| 1 | `E` | Jump into edit mode |

| 5 | `@` | Mention people |
| 6 | `Ctrl/Cmd + K` | Insert a link |
| 7 | `{` | Insert a macro |
| 8 | `#` + Space | Headings while typing |
| 9 | `M` | Comment |
| 10 | `?` | Show all shortcuts |
