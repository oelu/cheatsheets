# MacOS Keyboard Shortcuts

## Window Management

- `Cmd + M` minimize window
- `Cmd + H` hide app
- `Cmd + Option + H` hide other apps
- `Cmd + Ctrl + F` toggle fullscreen
- `Cmd + W` close window/tab
- `Cmd + Q` quit app

## Virtual Desktops

- `F3` show virtual desktops (Mission Control)
- `Ctrl + left/right` move to left or right virtual desktop
- `Ctrl + up` Mission Control
- `Ctrl + down` App Exposé (show windows of current app)

## Screenshots

- `Cmd + Shift + 3` full screen screenshot
- `Cmd + Shift + 4` selection screenshot
- `Cmd + Shift + 4 + Space` window screenshot
- `Cmd + Shift + 5` screenshot/recording toolbar
- `Cmd + Shift + 6` Touch Bar screenshot

Hold `Ctrl` with any screenshot shortcut to copy to clipboard instead of saving.

## Spotlight & Search

- `Cmd + Space` Spotlight search
- `Cmd + F` find in app

## App Switching

- `Cmd + Tab` switch apps
- `Cmd + ~` switch windows of same app
- `Cmd + Option + Esc` force quit dialog

## Text Editing

- `Cmd + A` select all
- `Cmd + C/V/X` copy/paste/cut
- `Cmd + Z` undo
- `Cmd + Shift + Z` redo
- `Option + left/right` jump by word
- `Cmd + left/right` jump to line start/end
- `Option + up/down` jump by paragraph
- `Cmd + up/down` jump to document start/end
- `Option + Delete` delete word backward
- `Fn + Delete` delete forward
- `Cmd + Delete` delete to line start

Add `Shift` to any navigation shortcut to select text.

## Finder

- `Cmd + N` new Finder window
- `Cmd + Shift + N` new folder
- `Cmd + Delete` move to trash
- `Cmd + Shift + Delete` empty trash
- `Space` Quick Look
- `Cmd + I` get info
- `Cmd + D` duplicate
- `Cmd + Shift + .` toggle hidden files
- `Cmd + 1/2/3/4` icon/list/column/gallery view
- `Cmd + [/]` back/forward
- `Cmd + up` go to parent folder
- `Cmd + down` open selected item

## System

- `Ctrl + Cmd + Q` lock screen
- `Cmd + ,` open preferences (in any app)
- `Cmd + Option + D` toggle Dock
- `Ctrl + Cmd + Space` emoji picker

## Accessibility

- `Cmd + Option + F5` accessibility options
- `Ctrl + F2` focus menu bar
- `Ctrl + F3` focus Dock
